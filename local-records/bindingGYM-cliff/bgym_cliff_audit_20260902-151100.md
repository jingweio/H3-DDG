## 1. Goal / hypothesis

### 1.1 用户原话（不改写、不弱化，2026-09-02）

> 我之前发现了一 mutation effect 中一个很有意思的现象，就是针对 一个 assay or 一个 complex-structure
> 发生 site mutation，大体的 mutation landscape 会按照不同的 mutation 程度呈现相对 smooth 的变化，就比如说
> mutant_i 和 mutant_j 之间的差异不大，比如说 seq-level 上比较相似，大部分都是呈现相似的 DMS-score /
> binding-stability-change (ddG)，但是很有可能存在一些 mutation 发生跳变的情况，比如说对 mutants 进行
> cluster，within cluster 可能会出现一些 mutant 对应的 DMS-score 显著高于或者低于平均数值，这种现象我将其
> 称之为 mutation-cliff or interaction-cliff。

### 1.2 拆成三个可独立否证的命题

| | 命题 | 形式化 | 主要度量 |
|---|---|---|---|
| **C1** | landscape 大体 smooth，且沿 mutation 程度变化 | `V(h)` 随 Hamming 距离 `h` 单调上升并饱和；近邻差异远小于随机对 | `SI = G(1)/GMD`、`V(1)/V(∞)`、`γ(1)`、`r/s` |
| **C2** | 存在少数近邻对发生跳变，超出 smooth landscape 能产生的幅度 | `ĉ` 的尾部相对 surrogate null 有超额质量 | `TR = Q.999/Q.75`、two-component mixture `π̂/ρ̂/ΔBIC`、`T(τ)` 扫描 |
| **C3** | 跳变是真的：不是测量噪声、不是人工假象 | 同一跳变在**别的背景／别的 aa 组合／别的测量**里复现，且不随采样深度走 | sibling slope `β`、site-pair ICC、`dR²_oos`、KRAS twin 复现率 `R`、密度分层 |
| **C4** | 「interaction」这个名字对不对 | cliff 位点是否富集在界面、且是否 partner-specific | burial-matched OR、AUROC(−d3d)、double-centered Mantel `M`、`F_spec` |
| **C5** | 这件事值不值得管 | 平滑预测器是否**系统性**在 cliff 上错 | `PSA_cliff`、`AUPSA` |

**核心恒等式（必须写进结论，避免把已知量包装成新指标）**：在共享 WT scaffold 上，
一个 Hamming-1 近邻对的大 `|Δy|`，**就是** background-dependent 的单点突变效应 ——
即 specific epistasis。`ĉ` 的分子 `e_{B∪i} − e_B = Δ_i(B) − β̂_i` 正是 Weinreich 2005 /
Ferretti 2016 / Poelwijk 2016 已定义的量。cliff 是这个已知量的**尾部**，不是一个新造的 index。

### 1.3 判读标准（跑数之前落笔，见 SPEC §1.2–1.6，此处只摘决定线）

- **C1 SUPPORTED**：`SI ≤ 0.50` ∧ `V(1)/V(∞) ≤ 0.35` ∧ `V(h)` 在 h=1..4 非降 ∧ `γ(1) ≥ 0.60`（CI 下界 > 0.45）
  **C1 REFUTED**：`SI ≥ 0.80` ∨ `V(1)/V(∞) ≥ 0.70` ∨ `V(1) > V(2)` ∨ `γ(1) ≤ 0.20` ∨ `pos_rs ≥ 0.70`
- **C2 SUPPORTED**：`TR` 超过 N1 集合的 99.5 分位 ∧ `T(τ) ≥ 2.0`（`q_BH < 0.05`）在 τ∈[3,8] **连续 ≥ 4 个点**
  且 σ 单位与 MAD 单位**两套都成立** ∧ `ΔBIC ≤ −10`（`π̂ ∈ [0.001, 0.05]`、`ρ̂ ≥ 3.0`）
  **C2 REFUTED**：`TR` 低于 N1 的 95 分位 ∨ `max T(τ) < 1.5` ∨ `ΔBIC > −10` ∨ `π̂` CI 上界 < 0.001
- **C3-L SUPPORTED**：`β` 超过其 N2 null 的 99.5 分位 ∧（`ICC ≥ 0.30` ∨ `dR²_oos ≥ 0.02` ∨ `AUROC_L5 ≥ 0.60`）
  **C3-L REFUTED**：`β` 落在 N2 的 95% 带内 ∧ ICC 上界 < 0.15 ∧ `dR²_oos` 上界 < 0.02
  → 即「偏差不复现」，**与异方差噪声不可区分，那就不许叫 cliff**
- **C4 「interaction cliff」LICENSED**：`F_spec ≥ 0.40`（噪声校正后）∧ KRAS 的 `p_NS3 < 0.05` ∧ cliff 位点的
  PSI 显著低于非 cliff 位点。**REFUTED ⇒ 正确的名字是「stability cliff」**，record 必须照此改称。
- **聚合**：按 **7 个 family**（不是 25 个 assay）计票；5-of-7 在 0.5 null 下 binomial p = 0.2266，
  所以票数只是**普遍性**陈述，**证据是逐 family 的 CI 与随机效应 meta**。

GPU 推断、模型训练、ProteinMPNN OOF 臂（`diagnostics/oof/` 不在本 branch，重算需要 GPU）。

### 1.5 ⚠️ 头号 limitation（写在这里，不写脚注）

**有效独立生物体系是 3–5 个，不是 7 个 family，更不是 25 个 assay。**
12 个 primary assay 里 5 个是 KRAS 打在 4 个近乎相同的界面上（其中 `KRAS_RAF1` 与 `KRAS_RAF1-RBD`
的逐残基结构注释**逐字节相同**）；25 个 registered assay 坐在 22 个 PDB 上；结构半场只有 7 个 assay 合格、

**不在 registry 里、`structures/` 里也没有它们的 PDB**，因此结构上是哑的。

**D9（⚠️ 这一条是 POST-HOC，看过 `V(h)` 之后才定的，因此按后验处理）**：预注册的单调性子句写的是
「`V(h)` 在 h=1..4 非降」，但它没预料到 dead zone。处理方式：

- **主表一律保留预注册规则的判读**（KRAS 三个 = 该子句 INCONCLUSIVE），不因为解释得通就改判；
- dead-zone 机制作为**独立发现**报告，附逐 assay 的峰值位置；
- 另加一列**明确标注为 post-hoc** 的次级判读「h=1..h_peak 上是否单调」。
  **这一列不得把任何 assay 升级成主表的 SUPPORTED。**

理由：规则是在见到数据之前写死的，事后发现规则的盲区可以报告、可以补次级分析，但不能回头改主判据 ——
否则「跑数前落笔」这件事就白做了。


### 3.3 口径（写死，后续所有数字按它算）

`ĉ_p = (e_{B∪i} − e_B) / sqrt(σ̂²(φ_B) + σ̂²(φ_{B∪i}))`，`e` 一律取 **5-fold out-of-fold** 残差
（in-sample 残差在稀有替换处被收缩最厉害，而那正是尾部所在，故只作敏感性列）；
`σ̂(φ)` 取 20 个等频 φ 桶内的 `1.4826 × MAD`（**MAD 永不用 SD**）；latent scale 为主、raw scale 为副，
**只在 raw 上成立而在 latent 上不成立的结论一律丢弃、不得作为正结果报告**。

### 3.4 尚未测量、故不预先承诺的量

墙钟、峰值 RSS、cliff 的数量级、G8 power、G9 aggregate-rule FPR。SPEC §5 给的是**预算**不是承诺。

## 7. 更正史

原处已就地标注，此处汇总索引。**这三条都是 SPEC 或设计阶段的错，被实测抓出来：**

1. **SPEC 的 h 轴自相矛盾** —— §1.0 按 `|KΔK|` 定义距离（nested=1、same-site=2），§1.2 的采样器却按
   code-vector 的 slot 数算（两类都=1）。实测判决合并轴才对（10/10 预declared SI 复现），处理见 **D1**。
   *SPEC §1.0 的「永不合并」只适用于 epistasis 统计量 `ĉ`，不适用于序列层面的 variogram。*

2. **SPEC 的 KRAS_SOS1 design/background 是侧向归属错误** —— 引用的 `0.264 / 0.110 = 2.4×` 把 ΔSASA 版
   design 比例除以了 partner 侧（chain S）的 5 Å 界面比例 49/440 = 0.1114。正确值 0.2147/0.2121 = 1.01×。
   这是 9 对预declared design/bg 里**唯一**不复现的一对，其余 8 对 4 位小数吻合。处理见 **D7**。

3. **设计阶段两个 agent 关于 BH3 相关系数的「矛盾」不是矛盾** —— `r = 0.1709`（Pearson）与 `+0.592`
   （Spearman）是同一个 518/518 join 上的两个不同统计量，实测同时复现为 +0.1709 / +0.5919。
   *教训：跨 agent 汇总数字时必须带统计量名，否则会误判成数据分歧。*

4. **`5A12_VEGF` 的「0/9 位点在 6.4 Å 内」这个 designed-negative 断言脆弱到第 4 位有效数字** ——
   最近的位点 H52A 落在 **6.4037 Å**，任何 6.5 Å 的截断或不同探针半径都会把它翻成 1/9。
   稳健形式是「9 个位点的 ΔSASA 全为 0.000 Å²」，C4 一律引用后者。
